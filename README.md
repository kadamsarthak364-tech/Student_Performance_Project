# 🎓 Student Performance Prediction System

## Project Overview
The Student Performance Prediction System is a Machine Learning project that predicts students' academic performance using their personal, educational, and subject score information.

The application is developed using Python and Streamlit.

## Features
- Student information input form
- Student performance prediction
- Machine Learning model integration
- Interactive web application
- Grade prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Machine Learning Model
- Algorithm: Logistic Regression
- Model Accuracy: 91.4% (on the current test split)
- Preprocessing: Simple Imputer and One-Hot Encoding

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/kadamsarthak364-tech/Student_Performance_Project.git
```

2. Open the project folder:

```bash
cd Student_Performance_Project
```

3. Create a virtual environment:

```bash
python -m venv .venv
```

4. Activate the environment on Windows:

```powershell
.venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
streamlit run app.py
```
